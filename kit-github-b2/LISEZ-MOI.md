# Kit étudiant GitHub B2 — Huit TP autonomes

Extraire tout le dossier puis ouvrir cours-interactif.html dans un navigateur.
Le carnet contient les huit TP et leurs restitutions. etudiants/ressources.html contient la préparation, le mémo et le dépannage.
Les captures et animations sont dans ressources-notions.html ; elles fonctionnent hors connexion.
Le dossier depot-etudiants contient les sources à cloner depuis le dépôt préparé par le formateur, les huit fiches et les huit trames de preuve dans ateliers/.
Outils fournis : diagnostic.py, verifier.py et build_docs.py dans tools/. Aucun paquet Python externe n'est nécessaire.
Le code initial comporte volontairement quatre défauts ; le vérificateur public échoue tant qu'ils ne sont pas corrigés.
Chaque atelier se termine par une restitution, un verdict argumenté d'un pair et une trace dans ateliers/preuves/.
Les couleurs YNOV sont conservées. Ce kit ne contient pas les corrigés du formateur.
Ne pas importer tout le kit dans GitHub : seuls les fichiers de depot-etudiants doivent figurer dans le dépôt de groupe.
